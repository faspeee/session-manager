# session-manager

[![Build Status](https://github.com/faspeee/session-manager/actions/workflows/ci.yml/badge.svg)](https://github.com/faspeee/session-manager/actions) [![License: MIT](https://img.shields.io/github/license/faspeee/session-manager)](./LICENSE)

A lightweight, stateless session‐management microservice written in Go, backed by MongoDB.  
Designed for cloud‐native environments, JWT‐based authentication, and auto‐expiring sessions.

---

## 🚀 Tech Stack

- **Language:** Go 1.20+  
- **Database:** MongoDB 6.x  
- **Container:** Docker & Docker Compose  
- **CI:** GitHub Actions  
- **Authentication:** JWT
